# Image asset rights

Michael ([@EmVeeNL](https://github.com/EmVeeNL)) confirmed on 2026-11-06 that he owns or has permission to publish `blixis-logo.webp` and `blixis-base-preview.png` in this public repository.

These images are excluded from the repository's GPL-2.0-or-later grant for code and documentation. Publication here does not grant separate reuse rights to third parties. Ask the maintainer before reusing or redistributing an image outside this repository.

`themes/blixis-showcase/screenshot.png` is a 1200×900 capture of the optional Showcase child theme, generated from the project's own markup and CSS. It contains no third-party image, and is covered by the repository's GPL-2.0-or-later grant. It is the screenshot WordPress displays for Blixis Showcase under Appearance → Themes; the separate concept preview above remains a design reference.

`themes/blixis-base/screenshot.png` is a 1200×900 capture of the neutral Blixis Base theme rendering a plain sample page on a disposable WordPress site (title "Example Site", no child theme, system fonts). It is not the concept preview, does not use the logo, contains no third-party image, and is covered by the repository's GPL-2.0-or-later grant. It is the screenshot WordPress displays for Blixis Base under Appearance → Themes. Base ships no other binary asset; the static check rejects any other Base binary and a Base screenshot that duplicates the concept preview or the Showcase screenshot.
