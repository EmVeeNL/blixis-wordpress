# Review architecture

## Instruction

Evaluate {COMPONENT} against architecture, PRD, security guidance, and ADRs. Provide risks, two alternatives, migration impact, and a testable recommendation.

## Required context

Provide the task ID, dependency status, relevant decisions, branch or diff, acceptance criteria, and test environment.

## Expected report

Summarize scope, concrete changes, exact test commands and results, risks, unresolved questions, and proposed task metadata changes. Never claim a PR, CI result, merge, or release without evidence. Follow [repository instructions](../../../AGENTS.md); do not include secrets in examples.
