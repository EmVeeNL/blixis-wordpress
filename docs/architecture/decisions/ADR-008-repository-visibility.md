# ADR-008 — Repository visibility policy

- **Date:** 2026-11-06
- **Status:** Proposed
- **Owner:** Project owner, confirmation pending

## Context

The project needs a stable contract for this boundary. This record came from the downloaded planning pack; provisional acceptance is a working hypothesis, not final owner approval.

## Decision under review

Review licensing and secret history before any visibility change; a later private setting does not erase earlier public copies.

## Alternative

Relying on future privacy to hide past exposure.

## Consequences and validation

Requires owner decision, license review, and continued secret scanning. Validate with a proof of concept, relevant unit/integration tests, and owner/security review before changing the status to Accepted.
